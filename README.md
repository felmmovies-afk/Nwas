# NEGM WEB LAB — PWA prototype

## الملفات والمسارات
- `index.html`: واجهة الاستوديو، رفع الملفات وفك ZIP والمعاينة والحفظ.
- `manifest.webmanifest`: تعريف تطبيق الويب القابل للتثبيت.
- `sw.js`: التخزين المؤقت الأساسي والعمل بعد أول تحميل.
- `icon.svg`: أيقونة التطبيق.

## التشغيل والتثبيت
ارفع الملفات الأربعة إلى استضافة HTTPS مثل GitHub Pages أو Cloudflare Pages. لا يعمل تثبيت PWA الكامل عادةً عند فتح `index.html` مباشرة من مدير الملفات. على Android افتح رابط الموقع في Chrome ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## ملاحظات مهمة
- فك ZIP يستخدم JSZip من CDN، وتكامل Firebase يستخدم SDK من CDN؛ يحتاجان اتصالًا بالإنترنت.
- حفظ الجهاز يستخدم localStorage وقد لا يناسب المشروعات الكبيرة.
- عنوان Firebase الموجود داخل `index.html` هو العنوان الذي زودني به المستخدم. نجاح الكتابة يعتمد على قواعد قاعدة البيانات. لا تفتح قواعد الكتابة للعامة في مشروع حقيقي؛ أضف تسجيل دخول وقواعد وصول لكل مستخدم.
- زر إعداد النشر لا ينشر الملفات على الإنترنت ولا ينشئ رابطًا عامًا حقيقيًا بعد. النشر الفعلي يتطلب ربطًا آمنًا باستضافة مثل Cloudflare Pages أو GitHub Pages عبر backend/Worker.
- المعاينة داخل iframe معزول نسبيًا، لكنها ليست بيئة تشغيل آمنة تمامًا لكود غير موثوق.
